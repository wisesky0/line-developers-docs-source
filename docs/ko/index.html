홈 / 개요

LINE Developers 문서

LINE Developers 문서에 오신 것을 환영합니다. 여기서는 LINE이 제공하는 다양한 API와 플랫폼에 대한 종합 가이드를 제공합니다.

💡 시작하기

처음이라면 시작하기 섹션에서 기본 개념을 학습한 후, 필요한 API를 선택하여 개발을 시작하세요.

주요 서비스

메시징 API

LINE 봇을 구축하고 사용자와 상호작용하기 위한 핵심 API입니다. 메시지 발송, 수신, 리치 메뉴, Flex 메시지 등 다양한 기능을 제공합니다.

  • 텍스트, 이미지, 영상 등 다양한 메시지 타입 지원
  • Flex 메시지로 복잡한 레이아웃 구성
  • 리치 메뉴를 통한 사용자 경험 향상
  • 빠른 회신으로 사용자 상호작용 개선

LINE Login

사용자 인증 및 프로필 정보 획득을 위한 OAuth 2.0 기반 로그인 서비스입니다.

  • 웹, 모바일 앱 등 다양한 플랫폼 지원
  • 사용자 정보 안전하게 관리
  • 통일된 로그인 경험 제공

LIFF (LINE Front-end Framework)

LINE 앱 내에서 웹 기반 UI를 구현할 수 있는 프레임워크입니다. 웹 기술을 사용하여 네이티브 앱과 유사한 경험을 제공합니다.

  • LINE 카메라, 위치 정보 등 기기 기능 접근
  • 메시징 API와 통합으로 강화된 기능
  • 개발자 친화적인 도구 및 라이브러리

LINE 미니앱

LINE 내에서 실행되는 경량 애플리케이션 플랫폼입니다. 별도 설치 없이 빠르고 편리한 서비스를 사용자에게 제공할 수 있습니다.

  • 빠른 로딩과 부드러운 사용자 경험
  • 결제 기능 통합 (국가별 지원)
  • 네이티브 기기 기능 활용
