# LINE Ads API 소개

LINE Ads API의 레퍼런스와 문서는 다른 사이트에서 제공됩니다.

- LINE Ads API
  - [Ad Tech API](https://ads.line.me/public-docs/certificated-ad-tech-general-partner)
  - [Data Provider API](https://ads.line.me/public-docs/data-general-partner)

<!-- note start -->

**LINE Ads API를 사용하려면 신청이 필요합니다**

LINE Ads API는 필요한 신청서를 제출한 법인 사용자만 사용할 수 있습니다. LINE Ads 계정과 함께 사용하려면 LINE Ads Manager에서 승인을 신청하십시오. 자세한 내용은 LINE for Business의 [LINE Ads API 사용하기](https://www.lycbiz.com/jp/manual/line-ads/other_011/)(일본어만 제공)를 참조하십시오.

<!-- note end -->
