# Mission Sticker API

<!-- note start -->

**선택 기능을 사용하려면 신청이 필요합니다**

필요한 신청서를 제출한 법인 사용자만 이 문서에 설명된 기능을 사용할 수 있습니다. LINE 공식 계정에서 이러한 기능을 사용하려면 영업 담당자 또는 [영업 파트너](https://www.lycbiz.com/jp/partner/sales/)에게 문의해 주십시오.

<!-- note end -->

## 개요 

미션 스티커는 특정 목표를 달성한 사용자에게 제공됩니다. 스티커를 보상으로 활용하여 사용자가 "ID 정보 연동", "회원 가입", "설문 응답" 등을 하도록 유도할 수 있습니다.

## API 레퍼런스 

API 사양에 대한 자세한 내용은 법인 고객용 API 레퍼런스의 [Mission Sticker API](https://developers.line.biz/en/reference/partner-docs/#mission-stickers)를 참조해 주십시오.

## 사용자가 미션 스티커를 다운로드할 수 없는 경우 

API 호출은 성공했지만 사용자가 미션 스티커 세트를 다운로드할 수 없다면, 다음 항목을 확인해 주십시오. 자세한 내용은 LINE 담당자에게 문의해 주십시오.

- 출시일, 채널 ID, 국가를 포함한 스티커 세트 정보가 정확한지 확인합니다.
- 사용자의 국가가 스티커 세트의 국가와 같은지 확인합니다.
- 대상 사용자가 이미 미션 스티커를 다운로드했는지 확인합니다.
