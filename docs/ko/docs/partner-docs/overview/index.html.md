# 개요

이 문서에서는 법인 사용자를 위한 선택 기능을 다룹니다.

이 페이지에서는 다음 선택 기능의 사용 방법을 설명합니다.

| 선택 기능 | 개요 |
| --- | --- |
| [오류 알림](https://developers.line.biz/en/docs/partner-docs/error-notification/) | LINE 플랫폼에서 웹훅 이벤트를 보낼 때 봇 서버가 오류를 반환하면, 채널 관리자에게 이메일로 알릴 수 있습니다. |
| [Provider 페이지](https://developers.line.biz/en/docs/partner-docs/provider-page/) | [Provider](https://developers.line.biz/en/glossary/#provider)가 LINE 플랫폼에서 제공하는 모든 서비스의 목록입니다. |
| [미션 스티커](https://developers.line.biz/en/docs/partner-docs/mission-stickers/) | 특정 목표를 달성한 사용자에게 미션 스티커가 제공됩니다. |
| [LINE 알림 메시지](https://developers.line.biz/en/docs/partner-docs/line-notification-messages/overview/) | 사용자 ID를 몰라도 전화번호를 지정하여 사용자에게 메시지를 보낼 수 있습니다. |
| [LINE Profile+](https://developers.line.biz/en/docs/partner-docs/line-profile-plus/) | 사용자가 LINE Profile+에 등록한 이름, 성별, 생년월일, 전화번호, 주소 등의 사용자 데이터를 Provider가 제공하는 서비스(웹 앱)에서 가져올 수 있습니다. |
| [LINE Beacon](https://developers.line.biz/en/docs/partner-docs/line-beacon/) | LINE Beacon을 수신하기 위한 조건을 설명합니다. |
| [모듈](https://developers.line.biz/en/docs/partner-docs/module/) | LINE 마켓플레이스에서 제공하는 확장 기능을 설명합니다. 모듈을 사용하면 Messaging API 채널을 개설하지 않은 LINE 공식 계정도 확장 기능으로 Messaging API의 고급 기능을 사용할 수 있습니다. |
| [Mark as read API(이전 버전)](https://developers.line.biz/en/docs/partner-docs/mark-as-read/) | 특정 사용자가 보낸 모든 메시지에 "읽음"을 표시할 수 있습니다. |

<!-- note start -->

**선택 기능을 사용하려면 신청이 필요합니다**

필요한 신청서를 제출한 법인 사용자만 이 문서에 설명된 기능을 사용할 수 있습니다. LINE 공식 계정에서 이러한 기능을 사용하려면 영업 담당자 또는 [영업 파트너](https://www.lycbiz.com/jp/partner/sales/)에게 문의해 주십시오.

<!-- note end -->
