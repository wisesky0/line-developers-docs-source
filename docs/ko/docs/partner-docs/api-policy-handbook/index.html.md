# LINE API 정책 핸드북

LINE API 정책 핸드북은 법인 고객을 위한 핸드북입니다. 이 핸드북은 [LINE 공식 계정 이용약관](https://terms2.line.me/official_account_terms_jp?country=JP&lang=en) 및 [LINE 공식 계정 API 이용약관](https://terms2.line.me/official_account_api_terms_jp?lang=ja&country=JP)(일본어로만 제공됩니다)과 관련된 문서이며, LINE API를 더 잘 이해하고 올바르게 사용하도록 돕기 위해 작성되었습니다.

새로운 기능이 추가됨에 따라 이 핸드북의 내용은 변경될 수 있습니다.

- [LINE API 정책 핸드북](https://vos.line-scdn.net/line-developers/docs/media/partner-docs/LINE_API_Policy_Handbook.pdf)(PDF)(일본어로만 제공됩니다)
