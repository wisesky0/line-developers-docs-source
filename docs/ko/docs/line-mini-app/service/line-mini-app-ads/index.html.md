# LINE MINI App에 광고 게재하기

LINE MINI App은 광고를 게재하여 수익화할 수 있습니다. 이 페이지에서는 LINE MINI App에 게재할 수 있는 광고의 종류와 게재 방법을 설명합니다. 광고는 인증된 MINI App과 미인증 MINI App 모두에 게재할 수 있지만, 서비스가 일본에서 제공되어야 합니다.

<!-- table of contents -->

## LINE MINI App에 게재할 수 있는 광고 

LINE MINI App에서는 [LY Ads Network Display Ads (Web)](https://www.lycbiz.com/jp/partner/adnetwork/ly-ads/)(일본어만 제공)를 게재하여 앱을 수익화할 수 있습니다. 안전하고 신뢰할 수 있는 사용자 경험을 위해 LINE MINI App은 LY Corporation의 심사와 승인을 받은 광고만 게재하며, 이를 위해 LY Ads가 광고 네트워크로 지정되어 있습니다.

## LINE MINI App에 LY Ads를 게재하는 방법 

LINE MINI App에 LY Ads Network Display Ads (Web)를 게재하려면 다음 단계를 따르세요.

2026년 3월 31일까지 기존 Yahoo! JAPAN Ads의 네트워크 파트너가 되었거나, 2026년 4월 1일 이후 LY Ads Network Display Ads (Web)의 네트워크 파트너가 되었다면 3단계로 넘어가세요.

- [1. 문서 확인하기](https://developers.line.biz/en/docs/line-mini-app/service/line-mini-app-ads/#how-to-place-line-mini-app-ads-step-1)
- [2. 네트워크 파트너 신청하기](https://developers.line.biz/en/docs/line-mini-app/service/line-mini-app-ads/#how-to-place-line-mini-app-ads-step-2)
- [3. LY Ads 사이트 심사 신청하기](https://developers.line.biz/en/docs/line-mini-app/service/line-mini-app-ads/#how-to-place-line-mini-app-ads-step-3)

각 단계를 설명합니다.

### 1. 문서 확인하기 

먼저 아래 링크에서 LINE MINI App 광고와 관련된 문서를 확인하세요. 이 자료에는 LINE MINI App에 광고를 게재하는 절차, LY Ads 사이트 심사, 주의 사항 등이 포함되어 있습니다. 자료를 확인한 다음 문제가 없다면 2단계로 진행하세요.

[문서(PDF)](https://s.yimg.jp/images/listing/partnerportal/document/yahooads_networkpartner_lineminiapp.pdf)(일본어만 제공)

### 2. 네트워크 파트너 신청하기 

LINE MINI App에 광고를 게재하려면 LY Ads Network Display Ads (Web)의 네트워크 파트너가 되어야 합니다. 아래 링크에서 네트워크 파트너를 신청하세요. 신청할 때 [파트너 네트워크 이용약관](https://s.yimg.jp/images/marketing/portal/paper/partner_network_terms_of_use.pdf)(일본어만 제공)을 확인하세요.

[신청 양식](https://form-business.yahoo.co.jp/claris/enqueteForm?inquiry_type=publisher_pn_application)(일본어만 제공)

<!-- note start -->

**다른 플랜을 사용한 적이 있더라도 네트워크 파트너 플랜을 별도로 신청해야 합니다**

이전에 LY Ads Network Display Ads (App) 또는 LY Ads Network Search Ads를 사용한 적이 있더라도, LY Ads Network Display Ads (Web)의 네트워크 파트너가 되려면 별도로 신청해야 합니다.

<!-- note end -->

### 3. LY Ads 사이트 심사 신청하기 

네트워크 파트너로 등록하면 광고 관리 도구(Network Partner Tool)에 로그인할 수 있습니다. 이 도구에서 광고를 게재할 LINE MINI App을 LY Ads 사이트 심사에 제출하세요.

LY Ads 사이트 심사를 통과하면 도구에서 광고 게재용 태그를 발급받을 수 있습니다. 이후에는 승인 후 제공되는 문서의 안내에 따라 진행하세요.
