# 인증된 MINI App 업데이트 후 재심사

LINE MINI App이 인증된 MINI App이 된 후 [LINE Developers Console](https://developers.line.biz/console/)에서 다음 정보를 변경하면 재심사가 필요합니다. 그 밖의 모든 정보는 심사 없이 자유롭게 변경할 수 있습니다.

| LINE MINI App 채널 탭 | 재심사가 필요한 정보 |
| --- | --- |
| Basic settings | <ul><li>채널 아이콘</li><li>채널 이름</li><li>채널 설명</li><li>이메일 주소</li><li>개인정보 처리방침 URL</li><li>이용약관 URL</li><li>현지화 (다국어 지원)</li><li>연결된 LINE 공식 계정</li></ul> |
| Web app settings | <ul><li>shareTargetPicker</li><li>채널 동의 간소화 (\*)</li><li>Published 엔드포인트 URL</li><li>스코프</li><li>친구 추가 옵션</li></ul>\* "채널 동의 간소화" 기능은 [2026년 1월 8일](https://developers.line.biz/en/news/2026/01/08/channel-consent-simplification/) 이전에 만들어진 일본의 LINE MINI App 채널만 변경할 수 있습니다. |
| Business information | <ul><li>서비스 회사 정보</li><li>개발 회사 정보</li><li>제공자 정보</li></ul> |
| Contact information | 모든 정보 |
| Service message template | 모든 정보 |
| In-app purchase | **Apply to use in-app purchase** 탭의 정보<br />\* 인앱 구매 정보를 변경하면 인앱 구매에 대한 재심사도 필요합니다. |

LINE Developers Console에서 설정하지 않는 변경 사항에는 재심사가 필요하지 않습니다. 다만 서비스 내용이나 기능을 업데이트할 때는 반드시 [LINE MINI App 정책](https://terms2.line.me/LINE_MINI_App?lang=en)을 준수해야 합니다.

업데이트 내용이 LINE MINI App으로 게재될 수 있는지 미리 확인하고 싶다면, LINE for Business의 [인증된 MINI App의 서비스 내용이나 기능을 업데이트할 때 변경 사항이 게재될 수 있는지 확인하는 방법이 있나요?](https://help.linebiz.com/lineadshelp/s/article/L000002146?language=ja)(일본어만 제공)를 참고하세요.

게재된 LINE MINI App에서 부적절하다고 판단되는 표현이 확인되면(모든 콘텐츠와 크리에이티브를 포함), 즉시 시정해야 합니다. 이를 이행하지 않으면 제재를 받을 수 있습니다. 자세한 내용은 [LINE MINI App 정책](https://terms2.line.me/LINE_MINI_App?lang=en)의 제재 항목을 참고하세요.

<!-- tip start -->

**게재된 LINE MINI App의 일시 중단**

점검 등 정당한 사유로 Published **Endpoint URL**을 다른 URL로 일시 교체하는 경우에는 LINE MINI App의 재심사를 요청할 필요가 없습니다. **Endpoint URL**을 변경하면 즉시 페이지가 전환됩니다.

<!-- tip end -->

자세한 내용은 [LINE MINI App 제출하기](https://developers.line.biz/en/docs/line-mini-app/submit/submission-guide/)를 참고하세요.
