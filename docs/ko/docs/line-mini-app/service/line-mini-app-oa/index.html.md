# LINE 공식 계정 활용하기

이 페이지에서는 LINE 공식 계정을 활용하여 LINE MINI App을 홍보하는 방법을 소개합니다. LINE 공식 계정을 만드는 방법은 Messaging API 문서의 [LINE 공식 계정 만들기](https://developers.line.biz/en/docs/messaging-api/getting-started/#create-oa)를 참고하세요.

![LINE 공식 계정에서 LINE MINI App 홍보하기](https://developers.line.biz/media/line-mini-app/mini_with_oa.webp)

## 리치 메시지 보내기 

시각적으로 눈에 띄는 리치 메시지를 보내면 사용자가 LINE MINI App의 가치를 빠르게 이해하고 더 많은 사용자가 LINE MINI App에 접속하도록 유도할 수 있습니다.

리치 메시지에 대한 자세한 내용은 LINE for Business의 [리치 메시지](https://www.lycbiz.com/jp/manual/OfficialAccountManager/rich-messages/)(일본어만 제공)를 참고하세요.

## 리치 메뉴에 LINE MINI App 링크 설정하기 

LINE MINI App의 [LIFF URL](https://developers.line.biz/en/glossary/#liff-url) 또는 [퍼머넌트 링크](https://developers.line.biz/en/glossary/#permanent-link-liff)를 리치 메뉴에 설정하면, 사용자가 LINE 공식 계정 채팅 화면에서 LINE MINI App에 쉽게 접속할 수 있습니다.

리치 메뉴에 대한 자세한 내용은 Messaging API 문서의 [리치 메뉴 개요](https://developers.line.biz/en/docs/messaging-api/rich-menus-overview/)를 참고하세요.
