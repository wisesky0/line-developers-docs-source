# 로딩 아이콘

로딩 아이콘은 LINE MINI App에서 권장하는 UI 요소입니다.

스피너(svg 파일)를 다운로드하여 로딩 아이콘으로 사용하세요.

- 라이트 모드 스피너([다운로드](https://developers.line.biz/media/line-mini-app/LINE_spinner_light.svg))
- 다크 모드 스피너([다운로드](https://developers.line.biz/media/line-mini-app/LINE_spinner_dark.svg))

스피너의 크기는 30x30 픽셀입니다.
스피너를 가운데 정렬하세요.
