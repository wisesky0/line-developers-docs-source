# LINE SDK for Flutter

LINE SDK for Flutter는 [Dart](https://dart.dev/)로 작성한 Flutter 앱에서 [LINE SDK for iOS](https://developers.line.biz/en/docs/line-login-sdks/ios-sdk/)와 [LINE SDK for Android](https://developers.line.biz/en/docs/line-login-sdks/android-sdk/)의 기능을 사용할 수 있게 해 주는 [Flutter](https://flutter.dev/) 플러그인입니다.

이 플러그인을 사용하면 앱에 LINE Login 기능을 쉽게 통합할 수 있습니다. 사용자를 LINE 또는 로그인 페이지로 이동시켜 LINE 계정 정보로 로그인하도록 안내할 수 있습니다.

## GitHub 저장소 

LINE SDK for Flutter는 오픈소스 프로젝트입니다. 코드와 README는 [GitHub](https://github.com/line/flutter_line_sdk/)에서 확인할 수 있습니다.

## API 레퍼런스 

모든 클래스와 메서드는 [Dart packages](https://pub.dev/documentation/flutter_line_sdk/latest/flutter_line_sdk/) 웹사이트에 문서화되어 있습니다.
