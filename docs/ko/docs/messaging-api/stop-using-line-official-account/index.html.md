# LINE 공식 계정 사용 중단하기

<!-- tip start -->

**Messaging API 사용 중단하기**

Messaging API 채널에 연결된 LINE 공식 계정은 계속 사용하면서 Messaging API만 중단하려면 [Messaging API 사용 중단하기](https://developers.line.biz/en/docs/messaging-api/stop-using-messaging-api/)를 참고하십시오.

<!-- tip end -->

Messaging API 채널에 연결된 LINE 공식 계정의 사용을 중단하려면 아래 단계에 따라 LINE 공식 계정을 삭제하십시오. Messaging API 채널에 연결된 LINE 공식 계정을 삭제하면 Messaging API 채널도 함께 삭제됩니다.

1. [LINE Developers Console](https://developers.line.biz/console/)에서 삭제할 Messaging API 채널을 선택하십시오.
2. **Basic settings** 탭이 나타납니다. "Delete this channel" 섹션에서 **Delete**를 클릭하십시오.

![](https://developers.line.biz/media/messaging-api/stop-using-line-official-account/delete-this-channel-en.webp)

3. "Delete this channel?" 모달이 나타납니다. **Go to LINE Official Account Manager**를 클릭하십시오.

![](https://developers.line.biz/media/messaging-api/stop-using-line-official-account/display-line-official-account-manager-en.webp)

4. LINE Official Account Manager가 새 탭에서 열리고 "Delete LINE official account" 화면이 나타납니다. 이후 단계는 LINE Official Account Manager에서 진행합니다. **I agree to the above and wish to permanently delete my LINE official account**를 체크하고 **Delete account**를 클릭하십시오.

![](https://developers.line.biz/media/messaging-api/stop-using-line-official-account/delete-account-en.webp)

<!-- note start -->

**"Delete LINE official account" 화면 대신 "403 Forbidden"이 표시되는 경우**

LINE 공식 계정을 삭제하려면 관리자(Admin) 역할이 있어야 합니다. LINE 공식 계정의 관리자 역할은 [LINE Official Account Manager](https://manager.line.biz)에서 설정할 수 있습니다. 자세한 내용은 LINE for Business의 [권한 설정](https://www.lycbiz.com/jp/manual/OfficialAccountManager/account-settings_permission/) 및 [LINE 공식 계정의 관리자 추가 또는 변경](https://help.linebiz.com/lineadshelp/s/article/L000001104?language=ja)(일본어로만 제공)을 참고하십시오.

<!-- note end -->

5. "Permanently delete this LINE official account?" 모달이 나타납니다. **Delete**를 클릭하면 LINE 공식 계정이 삭제되고, LINE 공식 계정에 연결된 Messaging API 채널도 함께 삭제됩니다.

![](https://developers.line.biz/media/messaging-api/stop-using-line-official-account/delete-en.webp)
