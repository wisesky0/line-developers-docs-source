# LINE Bot Designer

<!-- note start -->

**LINE Bot Designer 개발이 종료되었습니다**

[2022년 1월 18일](https://developers.line.biz/en/news/2022/01/18/development-of-line-bot-designer-has-been-finished/)에 발표된 것처럼 LINE Bot Designer는 더 이상 유지 보수되지 않습니다. [Flex Message](https://developers.line.biz/en/reference/messaging-api/#flex-message) 프로토타입을 만들려면 [Flex Message Simulator](https://developers.line.biz/flex-simulator/)를 사용하는 것을 권장합니다.

<!-- note end -->

LINE Bot Designer는 챗봇을 쉽고 빠르게 설계할 수 있도록 LINE 봇 프로토타입을 만드는 도구입니다. 이 도구를 사용하는 데 프로그래밍 지식은 필요하지 않습니다.

![LINE Bot Designer](https://developers.line.biz/media/messaging-api/using-bot-designer/bot-designer.webp)

## LINE Bot Designer 다운로드 

LINE Bot Designer는 무료로 제공됩니다. 도구를 실행할 때 LINE 계정으로 로그인하기만 하면 됩니다. 사용자 가이드는 이 [매뉴얼](https://vos.line-scdn.net/line-developers/docs/media/messaging-api/using-bot-designer/bot-designer-user-manual.pdf)(PDF)을 참고하세요.

[다운로드 페이지](https://developers.line.biz/en/docs/messaging-api/download-bot-designer/)에서 LINE Bot Designer를 다운로드하세요.

## 권장 환경 

LINE Bot Designer를 사용하려면 다음 환경 버전을 권장합니다.

- Windows 10
- macOS(Sierra 이상)
