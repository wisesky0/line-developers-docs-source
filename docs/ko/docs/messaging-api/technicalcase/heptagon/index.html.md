## 서비스 제공자가 시스템 개발에 대해 생각하는 것 

COVID-19 팬데믹 기간 동안 대면 행사를 더 이상 개최할 수 없게 되자, 미사와시에서 이주 및 정착에 관해 상담할 수 있는 온라인 시스템을 구축해 달라는 요청을 받았습니다. 프로젝트가 회계연도 중간에 시작되어 예산이 제한적이었기 때문에, 시 직원의 운영 부담을 최소화하면서 가능한 한 많은 사람이 사용할 수 있는 시스템을 개발해야 했습니다.

이러한 요구 사항을 충족하기 위해 다음과 같은 개발 방향에 빠르게 합의했습니다.

- 이미 많은 사람들이 사용하고 있는 플랫폼인 LINE을 인터페이스로 사용합니다.
- 예상되는 문의에 대해서는 AI를 사용하여 자동 응답을 제공합니다.
- 운영 비용을 낮게 유지하기 위해 작게 시작할 수 있는 서버리스 아키텍처를 채택합니다.
- 모든 것을 처음부터 만드는 대신 클라우드 벤더가 제공하는 API와 SaaS 등 클라우드 네이티브 기술을 활용하여 개발 공수를 줄입니다.
- 출시 후 운영을 외부 벤더에 의존하지 않고 주로 시 직원이 처리할 수 있도록 합니다.

이 프로젝트는 우리의 기술력을 지방 자치체를 지원하는 데 적용할 수 있는 이상적인 기회라고 보았고, 그래서 프로젝트를 추진하기로 결정했습니다.

### AWS로 개발 공수와 운영 비용을 최소화하기 

우리의 핵심 전문 분야인 AWS를 API 백엔드의 중심에 두었습니다. 관리 인터페이스로는 AI 챗봇을 쉽게 구축할 수 있는 Azure QnA Maker와, 시 직원들이 이미 익숙하게 사용하고 있던 Google Sheets를 도입했습니다. 프로젝트를 승인된 예산 내에서 유지하기 위해 개발 공수를 최소한으로 줄였고, 서비스 출시 후에 이용 요금과 운영 비용이 증가하지 않도록 서비스를 조합했습니다.

### 지속적인 클라우드 인프라 및 운영 비용 

백엔드 컴퓨팅 환경은 AWS Lambda를 중심으로 한 서버리스 아키텍처를 채택하고 있습니다. 이메일 전송, 데이터베이스, 스토리지는 모두 완전 관리형 종량제 서비스로 제공됩니다. 이 방식은 고정 인프라 비용을 없애고 지속적인 운영 비용을 낮게 유지합니다. 현재 규모에서는 이러한 서비스 대부분이 각각의 무료 티어 내에서 운영되고 있습니다.

### 인프라를 지원하는 운영 도구 

Serverless Framework(배포 및 구성 관리) / CloudWatch(모니터링) / Zabbix(모니터링)

### LINE API로 지역의 과제 해결하기 

LINE 공식 계정은 이미 지방에서도 널리 사용되고 있지만, LINE API를 활용하면 제공할 수 있는 서비스의 범위가 크게 넓어집니다. LINE을 활용한 서비스를 통해 지역 공동체가 직면한 과제를 해결하고자 합니다.

### 새로운 서비스를 개발하는 분들께 드리는 메시지 

LINE 생태계를 활용하면, 개발자는 사용자에게 사용하기 쉽고 익숙한 인터페이스를 제공하면서 개발 공수를 크게 줄일 수 있습니다. 또한 LINE을 기업의 핵심 역량과 결합하면 더 많은 사람들이 쉽게 이용할 수 있는 서비스를 제공할 기회가 커집니다. 개발 옵션 중 하나로 LINE을 포함하는 것이 강력한 전략적 이점이 될 수 있다고 믿습니다.
