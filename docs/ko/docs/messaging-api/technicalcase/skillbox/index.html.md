## SkillBox, 칭찬 기반 멘토 시스템 

SkillBox는 참여도를 손쉽게 높여 주는 칭찬 기반 멘토 시스템입니다. 참여도가 낮은 조직과 높은 조직을 비교해 보면, 참여도가 낮은 조직에는 직원을 격려하는 문화가 부족한 반면, 참여도가 높은 조직은 "잘하고 있어요!", "어려운 점이 있나요?", "계속 힘내세요!"와 같이 자주 지지하는 피드백을 제공합니다. SkillBox는 신입 직원과 선배 직원이 매주 1~2분의 상호작용만으로도 서로에게 긍정적인 피드백을 자주 주고받을 수 있는 상황을 자연스럽게 만들어, 참여도를 높입니다.

구체적으로, 신입 직원은 미리 정해진 액션 목록의 각 항목에 대해 "완료"와 "미완료" 중 하나를 선택하여 매주 자기 점검을 합니다. 자기 점검 화면에는 신입 직원이 노력한 내용을 공유하거나 조언을 구할 수 있는 선택 입력 자유 텍스트 필드도 있어, 멘토에게 현재 상태를 보고할 수 있습니다. 멘토는 스티커나 댓글로 점검 내용에 반응할 수 있으며, 이러한 상호작용을 통해 멘토로서 필요한 후속 조치를 손쉽게 제공할 수 있습니다.

SkillBox를 통해 우리는 젊은 직원의 조기 퇴사 문제를 해결하고자 합니다. 대학 졸업자의 30% 이상이 입사 후 3년 이내에 회사를 떠나며,(\*1) 많은 조직이 젊은 직원의 퇴사를 심각한 문제로 보고 있습니다. 멘토 프로그램은 이 문제를 해결하는 한 가지 방법입니다. 이 프로그램은 48%의 기업에서 도입되었으며, 도입한 기업의 70%가 프로그램이 효과적이라고 보고하고 있습니다.(\*2) 그러나 많은 경우 멘토는 대개 선배 직원이며, 정기 면담 등으로 인한 부담이 큽니다. 그 결과 이러한 프로그램은 개별 팀의 재량에 따라 형식적인 절차로 전락하기도 합니다. SkillBox를 활용하면 기업은 멘토의 부담을 최소화하고 멘토링 시스템이 제대로 작동하도록 보장하여, 퇴사율을 더욱 낮출 수 있습니다.

\*1: [후생노동성: "신규 졸업자의 취업 현황(2020년 3월 졸업자)"](https://www.mhlw.go.jp/content/11805001/001158687.pdf)

\*2: [HR 연구소: "직원 육성에 관한 조사: 신입사원 연수" – 조사 결과 보고서(2020)](https://hr-souken.jp/research/2550/)

## 시스템 개요

### AWS 기반 프로젝트의 기술 아키텍처 

프로젝트의 핵심 시스템 인프라로 Amazon Web Services(AWS)를 선택했습니다. 백엔드에는 기계 학습 모델을 쉽게 통합할 수 있는 프로그래밍 언어인 Python을 사용합니다. 프로젝트 프레임워크로는 ECS와 Lambda 모두에서 원활하게 실행되는 경량 프레임워크인 Flask를 도입했습니다. 또한 CloudFront와 S3를 사용하여 Vue.js가 실행되는 프런트엔드 환경을, ECS와 Flask를 사용하여 백엔드 환경을 구축했습니다. 데이터베이스로는 Amazon Aurora를 사용합니다. ECS는 LINE API의 콜백을 처리하고, AWS Lambda는 LINE API를 통해 사용자에게 예약된 알림 프로세스를 실행합니다. 지속적 통합(CI)에는 GitHub Actions를, 지속적 배포(CD)에는 AWS CodePipeline을 사용합니다. 이 프로젝트에서 LINE은 알림 목적으로만 사용되므로, LINE WORKS와 Messaging API를 사용합니다.

### 응답 습관을 형성하고 퇴사율 감소에 기여하기 

SkillBox는 현재 회사 이메일 주소가 없는 직원이 있는 기업에서도 도입되고 있습니다. LINE API 연동(LINE WORKS 및 Messaging API)을 사용하여 SkillBox를 도입한 기업들은 간단하고 사용하기 쉽다는 점에서 매우 좋은 평가를 주었습니다. 예를 들어, 일본 전국에서 뷰티 클리닉을 운영하는 Olive Spa의 사례가 있습니다. 이 회사는 이전에 종이 기반 일일 보고서로 신입 직원을 지원했습니다. SkillBox는 그 방식을 편리하게 발전시킨 형태로 좋은 평가를 받았습니다. 개인 스마트폰 사용과 관련하여, 이 회사는 "운영을 시작할 때 전혀 문제가 없었고, 직장에서도 순조롭게 받아들여졌다"고 했으며, "직원 퇴사를 방지하는 데 도움이 되고 있다고 실제로 느낀다"고도 말했습니다. (\*4)

\*4: [SkillBox 사례 연구: Olive Spa Co., Ltd.](https://www.skillbox.jp/eduken/interview006)

### SkillBox 기능 개선의 향후 전망 

시간이 지남에 따라 SkillBox를 더욱 편리하게 사용하고 더 큰 성과를 낼 수 있도록 계속 개선할 계획입니다. 우리가 내부적으로 강조하는 원칙 중 하나는 시스템이 사용자에게 즐거워야 한다는 것입니다. 여기에는 게이미피케이션을 통해 게임 요소를 도입하는 것과 같은 기능적 측면은 물론, 부담 없이 자연스럽게 응답하는 습관을 장려하는 방법과 같은 운영상의 고려 사항도 포함됩니다. 따라서 응답 요청 알림을 어떻게 전달할지, 그리고 응답을 제출할 때 어떤 기기를 사용할지를 지속적으로 재검토하는 것이 중요하다고 생각합니다. 이와 관련하여 LINE과의 API 연동을 더욱 정교하게 다듬으면 추가적인 기회가 생길 수 있습니다. 예를 들어 향후 아이디어로는 사용자가 LINE 공식 계정에서 직접 SkillBox에 응답을 제출하거나, SkillBox에 달린 댓글을 공식 계정에서 바로 읽을 수 있도록 하는 것이 있습니다. 아직은 구상 단계이지만, SkillBox를 사용자에게 더욱 편리하게 만드는 노력을 계속해 나갈 것입니다.

### LINE API에 대한 요청 

LINE API는 방대한 문서를 제공하고 있어, 원활하게 구현할 수 있었습니다. 현재는 LINE을 통해 알림을 보내고 사용자가 웹에서 응답을 입력하지만, LINE 안에서 직접 응답할 수 있도록 하는 방안도 검토했습니다. 그러나 여러 항목을 선택하거나 입력해야 하는 양식의 경우, 제출한 응답을 취소하거나 수정하는 흐름이 복잡해지는 경향이 있어 이 방식은 추진하지 않기로 했습니다. 알림 처리에는 LINE WORKS API도 사용하고 있습니다. 일부 경우에는 제공되는 오류 메시지의 정보가 제한적이어서, 오류의 정확한 원인을 파악하거나 단일 요인으로 좁히기 어려웠습니다.

### 새로운 서비스를 개발하는 분들께 드리는 메시지 

LINE API를 사용하는 서비스를 2년 이상 운영해 오고 있습니다. 지금까지 통신 오류나 기타 문제는 거의 없었으며, 동시에 사용하고 있는 유사한 타사 서비스보다 일관되게 더 안정적이라는 것이 입증되었습니다.
